# 작은 합성 데이터

`scripts/generate-demo-data.py`가 만드는 가상 인물 24명, 거래 1,344행이다. 2026년 1~7월의 자료가 모두 준비되어 있다는 전제이며 실제 개인·은행 자료가 아니다. 프로필의 `data_range` 전체를 한 트랜잭션으로 적재하므로 해당 기간에 원장 행이 없는 사람은 무거래자로 본다. 향후 부분 수집을 도입하면 수집 완료 기간을 별도로 관리해야 한다.

일반 통합 테스트와 로컬 시연이 이 폴더를 사용한다. CSV 쉼표·줄바꿈·BOM도 포함한다. 성능 실험은 이 작은 자료의 응답시간을 대규모 효과로 주장하지 않고 별도의 결정적 SQL 시드를 사용한다.
