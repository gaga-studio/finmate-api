# FinMate 최종발표 주장·출처표 v1

> 기준일: 2026-07-13  
> 목적: 발표 문장을 근거가 허용하는 범위 안에 고정한다. 이 문서는 참고 링크
> 목록이 아니라, 슬라이드 문구를 검수하는 주장 계약이다.

## 1. 사용 규칙

1. 슬라이드의 외부 숫자·서비스 사실·구현 수치는 아래 `Claim ID`에 연결한다.
2. `허용 문구`보다 강한 인과·효과 표현으로 바꾸지 않는다.
3. 외부 연구는 FinMate의 효과가 아니라 **설계 근거**로만 사용한다.
4. 내부 구현 수치와 사용성 결과는 발표 48시간 전에 다시 실행·확인한다.
5. 제안 수치는 검증 결과처럼 말하지 않고 항상 `제안` 또는 `목표`로 표시한다.
6. 출처가 서로 다른 숫자를 하나의 효과 크기처럼 더하거나 비교하지 않는다.

## 4. 연구를 한 장에 넣을 때의 정확한 연결

```text
목표 설정 연구
→ 사용자가 목표를 직접 확인·확정하게 한다

게임형 금융교육 연구
→ 캐릭터와 레이드는 이해를 돕는 표현으로만 쓴다

그룹저축 연구
→ 루틴의 유지기간과 작은 행동을 보여준다

상향 비교·거래앱 연구
→ 정확 금액·순위·거래 보상을 제거한다
```

연구가 직접 증명하지 않은 `익명 모험가 추천`, `루틴 개인화`, `자동 레이드`의
효과를 연구 결과에 기대어 확정적으로 말하지 않는다. 이것들은 FinMate가 검증해야
할 제품 가설이다.

## 6. 발표 직전 출처 QA

- [ ] C01의 배점을 `서류심사`라고 표시했고 최종 심사표라고 부르지 않았다.
- [ ] 2장의 조사 대상·연도·전체 비교값이 원문과 일치한다.
- [ ] `+0.313SD`, `3.7배`, `9,000명 이상`을 FinMate 성과처럼 표현하지 않았다.
- [ ] 4장의 월 50만원이 합성 사례이며 안전성 검사를 생략한 단순 복사가 아님을 적었다.
- [ ] 7장과 B10은 같은 경로를 사용한다. 결과형이면 모든 숫자를 실제 원자료에서 집계했고, 계획형이면 숫자 대신 `아직 결과 없음`과 검증 설계만 표시했다.
