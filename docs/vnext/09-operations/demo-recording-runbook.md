# FinMate 결정적 90초 시연 녹화·동결 절차

## 1. 산출 규격

- `1920×1080`, H.264 High, AAC, `90.0초 ±0.5초`
- 네트워크 없이 재생 가능한 MP4
- 모바일 앱 화면은 중앙에 두고 주변은 단색 배경으로 구성
- 화면 하단에 `합성데이터 기반 결정적 프로토타입`을 상시 표시
- 외부 브랜드 로고, 실제 개인정보, 실제 상품 가입 화면은 포함하지 않음

## 2. 녹화 전 동결

아래 값을 `demo-record-manifest.json`에 기록한다.

- API·웹 commit SHA
- OpenAPI SHA-256
- 합성데이터 release·bundle SHA·L3 tree SHA
- demo fixture version
- 브라우저·Node.js·ffmpeg version
- 화면 크기와 device scale factor
- 녹화 시각과 생성 MP4 SHA-256

## 3. 장면 타임라인

[`90초 시연 시나리오`](../02-ux/demo-scenario-90s.md)를 기준으로 한다.

| 구간 | 화면 | 검수 문장 |
| ---: | --- | --- |
| 0–13초 | 온보딩·기준선 | 목표는 아직 활성화되지 않음 |
| 13–19초 | 목표 확정 | 200만→500만원, 2027년 1월 |
| 19–29초 | 홈·동물 리포트 | 네 분야의 역할과 계산 근거 분리 |
| 29–37초 | 퀘스트 | 수락 직후 레이드 불변 |
| 37–51초 | 메이트 | 친구·그룹·비교 탐색과 익명 모험가 |
| 51–64초 | 루틴 적용 | 상대 금액이 아닌 월 50만원 개인화 안 |
| 64–71초 | 하나 상품 정보 | 가입 없음, 진행 영향 없음 |
| 71–84초 | 기록 | 50만원×6회의 검증된 합성 저축 |
| 84–90초 | 완료 홈 | 500만원과 레이드 완료 근거 |

## 4. 녹화 검수

- [ ] 모든 장면이 동일한 API·fixture에서 재현됨
- [ ] 한글 잘림, 로딩 스피너 정지, 이미지 404, 콘솔 오류 없음
- [ ] 퀘스트 클릭만으로 레이드가 움직이지 않음
- [ ] 상품 정보 열람 전후 진행값 동일
- [ ] 월 전환과 6개 저축 이벤트 순서 일치
- [ ] 마지막 프레임에 5,000,000원과 데이터 근거 표시
- [ ] MP4를 네트워크 차단 상태에서 처음부터 끝까지 재생
- [ ] PPT 삽입본과 원본 MP4 SHA를 함께 기록

사용성 검증 결과와 최종 테스트 수치는 영상에 굽지 않는다. 발표 직전 변경될 수 있는
수치는 PPT 텍스트에서만 관리한다.
