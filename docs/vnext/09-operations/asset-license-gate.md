# FinMate 폰트·캐릭터·배경 에셋 릴리스 게이트

## 1. 원칙

디자인 전달본에 파일이 포함됐다는 사실만으로 배포 권한이 확인된 것은 아니다.
출처·권리자·허용 범위·수정·재배포 조건을 서면으로 확인하지 못한 에셋은 내부
프로토타입에서만 사용하고 production 배포를 차단한다.

## 2. 확인 대상

| 대상 | 현재 상태 | production 조건 | 미확인 시 대안 |
| --- | --- | --- | --- |
| Paperlogy WOFF2 | 라이선스 고지 미수령 | 웹 임베딩·상업 이용·재배포 허용 근거 | 시스템 sans-serif |
| 곰·물개·토끼·새 캐릭터 | 권리자 확인 대기 | 원본 제작자·양도/이용허락·수정 허용 | 승인된 임시 도형 에셋 |
| 레이드 보스·전투 배경 | 권리자 확인 대기 | 상업 서비스·영상·PPT 사용 범위 | 단색 배경·Lucide 아이콘 |
| 메이트 동물 에셋 | 권리자 확인 대기 | 파생 이미지와 크롭 허용 | 텍스트 아바타 |
| 기록 여정 배경 | 권리자 확인 대기 | 웹/PWA 배포·수정 허용 | CSS 단색 배경 |

## 3. 에셋 등록 필드

- 내부 asset ID와 저장 경로
- 파일 SHA-256
- 원본 제작자 또는 공급자
- 원본 링크·계약·이메일 등 권리 근거
- 허용 환경: 내부, 발표, demo, production
- 상업 이용, 수정, 재배포, 영상 캡처 허용 여부
- 표시 의무와 라이선스 문구
- 승인자와 승인일
- 만료·철회 조건

## 4. 배포 판정

- 모든 production bundle 에셋이 등록표에 존재해야 한다.
- `unknown`, 구두 확인, 출처 없는 생성물은 승인으로 보지 않는다.
- 생성형 이미지라면 사용 도구·생성일·입력 권리·후처리 기록을 보존한다.
- 라이선스가 충돌하면 더 제한적인 조건을 적용한다.
- 철회 시 새 build에서 제거하고 PWA cache version을 갱신한다.

## 5. 서면 확인 요청 문안

> 전달해 주신 폰트와 이미지 에셋을 FinMate 모바일 웹/PWA, 발표 영상과 외부 demo에
> 사용할 수 있는지 확인 부탁드립니다. 각 파일의 제작자·출처, 상업 이용, 수정,
> 웹 임베딩, 재배포 및 영상 캡처 허용 범위를 서면으로 남겨 주세요. 권리 확인이
> 어려운 파일은 production에서 대체하겠습니다.

현재 이 항목은 **미확인**이며, 통과 결과를 만들거나 추정하지 않는다.
