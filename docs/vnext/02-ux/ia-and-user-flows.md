# FinMate vNext IA와 사용자 흐름

## 1. 내비게이션 원칙

- 하단 내비게이션은 `홈 · 메이트 · 퀘스트 · 기록` 네 항목으로 고정한다.
- 활성 탭은 색상뿐 아니라 아이콘 채움과 텍스트로 구분한다.
- 목표 설정 흐름은 메이트의 비교 탐색에서 시작하고 확정 후 홈으로 돌아온다.
- 설정과 동의 관리는 각 관련 화면의 문맥 진입점과 프로필 메뉴에서 접근한다.
- MVP에 없는 친구·메이트 찾기 탭은 노출하지 않는다.

## 3. 핵심 흐름

### 3.1 첫 목표 확정

1. 사용자가 생활맥락, 돈 고민, 성향을 입력한다.
2. 익명 카드 공개의 선택 항목과 비공개 항목을 확인하고 선택한다.
3. 마이데이터 수집 항목, 목적, 전송 주기, 철회 방법을 확인한 뒤 연결한다.
4. 기준선 진단에서 네 동물의 초기 상태와 데이터 신뢰 상태를 확인한다.
5. 목표 없는 홈에서 `목표 찾기`를 선택한다.
6. 비교 탐색에서 유사 이유와 공개 배지를 확인하고 추천 모험가를 선택한다. 정확 코호트가 30명 미만이면 금융 수용력 제약을 유지한 채 비금융 생활맥락만 넓힌다. 처음 찾은 30명 이상 안전 코호트의 `GROUP_ROUTINE`만 MVP 프라이버시 대체 카드로 선택할 수 있고, 그런 코호트가 없으면 카드 없는 `INSUFFICIENT` 빈 상태를 본다.
7. 성장 방식 상세에서 개인 카드이면 루틴 근거·유지기간·공개 범위를, 30명 이상 그룹 루틴 카드이면 집계 루틴·구간·기준일을 확인하고 루틴 하나를 고른다.
8. 가볍게·표준·도전 후보의 목표값, 기간, 검증 방식, 기준일을 비교한다.
9. 선택한 후보와 동의·연결 상태를 최종 확인하고 목표를 확정한다. 동의가 변경·철회되었거나 오프라인이면 각각 재동의·재연결 경로를 완료한 뒤 새로 확인한다.
10. 홈에서 1단계 자동 레이드와 다음 퀘스트를 확인한다.

완료 조건: 활성 목표가 하나 생성되고 홈의 목표·진행률·레이드 단계·데이터 기준일이 같은 목표를 가리킨다.

### 3.2 퀘스트와 데이터 반영

1. 홈의 다음 행동 또는 퀘스트 탭에서 목표 연결 퀘스트를 연다.
2. 완료 조건과 검증 출처를 확인하고 행동을 시작한다.
3. 앱 안에서 검증되는 학습·기록은 즉시 완료된다.
4. 금융 데이터가 필요한 행동은 `데이터 반영 대기`로 전환된다.
5. 새 데이터가 도착하면 금융 스탯과 목표 지표를 별도로 재계산한다.
6. 활성 목표 지표가 변한 경우에만 짧은 레이드 연출이 재생된다.
7. 홈은 현재·최고 진행률과 다음 행동을 보여주고 다시 대기 상태가 된다.

완료 조건: 퀘스트 완료, 금융 스탯, 목표 진행률의 변경 이유가 각각 추적되며 같은 행동을 임의 중복 반영하지 않는다.

### 3.3 데이터가 오래되거나 확인이 필요한 흐름

1. 홈·목표·리포트 상단에 데이터 상태와 마지막 동기화를 표시한다.
2. `오래됨`이면 진행률과 레이드를 고정하고 `연결 상태 확인`을 제공한다.
3. `확인 필요`이면 불확실 거래 수와 영향을 설명하고 `거래 확인`을 제공한다.
4. 사용자가 거래를 분류하면 변경 요약을 확인한 뒤 재계산을 요청한다.
5. 최신 데이터가 확보되면 새 진행률과 변경 이유를 보여준다.

완료 조건: 확인 전 거래는 목표 계산에서 제외되며, 사용자가 수정 전후 결과를 구분할 수 있다.

### 3.4 목표 일시정지·재개·재설정

1. 홈의 목표 메뉴에서 `일시정지`를 선택하고 영향을 확인한다.
2. 일시정지 중에는 목표 상태가 `일시정지`로 유지되고 새 데이터로 진행률·레이드가 갱신되지 않는다. 목표 연결 퀘스트도 `일시정지`되어 완료 처리와 퀘스트 XP 지급이 중단되며 기록은 유지된다. 포인트·현금성·경제적 보상은 MVP에 존재하지 않는다.
3. 30일 이내이고 기준선 변화가 20% 미만이면 확인 후 즉시 재개한다.
4. 30일 초과 또는 기준선 변화 20% 이상이면 기존·새 기준선을 비교한다.
5. 새 후보를 선택·확정한 뒤 홈으로 돌아간다.

완료 조건: 기존 목표가 사용자 모르게 수정되지 않고 상태 전환과 재확정 이력이 기록된다.

### 3.5 공개 동의 철회

1. 설정 또는 추천 카드 공개 안내에서 `공개 범위 관리`로 진입한다.
2. 현재 공개 항목과 비공개 항목, 철회 영향을 확인한다.
3. 철회를 확정하면 새 추천에서 즉시 제외한다.
4. 캐시·파생 추천 제거가 진행 중이면 최대 처리 시점을 안내한다.
5. 개인 목표와 기록은 유지하되 원본 사용자를 식별할 연결은 제거한다.

완료 조건: 마이데이터 연결은 유지되고 익명 카드 공개만 독립적으로 철회된다.

## 5. 발표 데모 경로

데모는 4분 안에 제품의 인과관계와 안전 원칙을 보여준다.

1. **목표 없는 홈**: 네 동물과 `목표 찾기`를 보여주며 게임이 금융판단을 대신하지 않음을 설명한다.
2. **비교 탐색**: `월세 부담이 비슷해요`, `저축 시작 구간이 비슷해요`와 공개 배지를 확인한다.
3. **성장 방식**: 6개월 유지한 자동저축 루틴을 선택하고 정확 금액이 비공개임을 확인한다.
4. **목표 후보**: 내 저축률 기준선 8%에서 가볍게 11%, 표준 14%, 도전 17%가 계산된 근거를 비교한다.
5. **목표 확정**: 표준, 30일, 저축성 순유입 검증, 데이터 기준일을 확인한다.
6. **활성 레이드**: 1단계 보스 `비상금 공백`, 현재·최고 진행률, 다음 퀘스트를 보여준다.
7. **반영 대기**: 자동저축 확인 퀘스트 후 이전 진행률이 유지되는 이유를 보여준다.
8. **새 데이터 반영**: 짧은 전투와 진행률 상승, 목표 기록 스냅샷을 보여준다.
9. **투자 판단 리포트**: 수익률·거래 보상 없이 위험성향과 분산 학습만 제공함을 확인한다.

데모 성공 조건:

- 발표자가 “실제 익명 루틴 → 내 기준선 목표 → 실제 데이터 변화”의 세 단계를 화면으로 증명한다.
- 오래됨·반영 대기 상태가 실패가 아니며 이전값을 유지한다는 점을 설명한다.
- AI가 서버 허용 후보만 순위·설명하고 숫자는 만들지 않는다는 근거를 목표 후보 화면에서 확인한다.

## 6. Phase 2 확장 위치

- 메이트 아래에 `친구`와 `메이트 찾기`를 추가할 수 있으나 MVP 내비게이션에는 숨긴다.
- 그룹 루틴 카드는 정확 코호트가 30명 미만이고 30명 이상 안전 일반화 코호트를 찾았을 때의 MVP 프라이버시 대체물로만 사용한다. 안전 코호트가 없으면 카드가 없다. 유사그룹 탐색과 그룹 루틴 탐색·필터·집계 인사이트는 Phase 2다.
- 알림 설정과 레이드 연출 강도는 Phase 2이며, MVP는 운영체제 `동작 줄이기`를 즉시 존중한다.
- 확장 기능은 현재의 목표 후보 생성, 동의 분리, 투자 가드레일을 우회할 수 없다.
