# FinMate MVP QA·릴리스 체크리스트

## 1. 심각도

- `P0`: 개인정보·인증·금융 계산 오류, 데이터 손실, 앱 진입 불가. 릴리스 즉시 중단.
- `P1`: 대표 흐름 차단, 잘못된 목표·루틴·보상 인과, 주요 모바일 화면 사용 불가.
- `P2`: 우회 가능한 기능 오류, 일부 상태·카피·시각 결함.
- `P3`: 제품 동작을 바꾸지 않는 경미한 시각·문서 결함.

릴리스 조건은 `P0=0`, `P1=0`, 승인되지 않은 `P2=0`이다.

## 2. 계약·데이터

- [ ] OpenAPI 문법·예시·오류 응답 검증 통과
- [ ] 생성 TypeScript client가 원본 OpenAPI와 일치
- [ ] API 단위·통합·Testcontainers 테스트 통과
- [ ] 합성데이터 release·SHA-256·L3 tree digest 검증 통과
- [ ] 동일 seed 두 번 적재 시 중복 없음
- [ ] 금액은 정수 KRW, 비율은 basis point, 시각은 ISO 8601
- [ ] 계산 응답에 `calculationVersion`, `dataState`, `lastSyncedAt` 존재
- [ ] 여윳돈 0 이하·불규칙 소득·중복 거래·오래된 데이터 골든 테스트 통과

## 3. 대표 사용자 흐름

- [ ] 가입 → 온보딩 5단계 → 기준선 진단
- [ ] 목표 확정과 `일단 탐색하기`가 서로 다른 상태로 저장
- [ ] 목표 없는 사용자는 탐색만 가능하고 수락·적용 명령은 차단
- [ ] 홈 레이드와 네 동물 리포트가 서버 계산값만 표시
- [ ] 친구 읽기 화면에 정확 금액·순위 없음
- [ ] 그룹 → 모험가 → 비교 리포트 → 루틴 개인화 연결
- [ ] 루틴 교체 전 확인, 취소 시 기존 루틴 유지, 주 목표 불변
- [ ] 퀘스트 수락·완료와 금융데이터 반영 대기 분리
- [ ] 상품 정보 열람 전후 XP·스탯·레이드 불변
- [ ] 기록 월 이동, 미래 빈 월, 날짜 상세 합계 일치
- [ ] demo 시간 진행은 합성 사용자·demo profile에서만 가능

## 4. 공통 상태

- [ ] loading이 이전 값을 새 결과처럼 표시하지 않음
- [ ] empty에 이유와 시작 행동 하나가 있음
- [ ] `PENDING`에 검증 대기와 마지막 동기화가 보임
- [ ] `STALE`에서 새 진행이 멈추고 복구 행동이 보임
- [ ] `INSUFFICIENT`에서 부족 데이터와 행동형 대안이 보임
- [ ] API 오류에 재시도와 입력 보존이 있음
- [ ] 세션 만료 후 refresh 또는 로그인 복귀가 안정적임

## 5. 모바일·접근성

- [ ] 360px·390px·430px에서 가로 스크롤 없음
- [ ] 고정 하단 탭이 CTA·본문·바텀시트를 가리지 않음
- [ ] 긴 한국어·금액·날짜가 카드 밖으로 넘치지 않음
- [ ] 모든 이미지 요청 성공, 대체 텍스트 또는 장식 이미지 처리
- [ ] 아이콘 버튼에 접근 가능한 이름 존재
- [ ] 키보드만으로 폼·탭·다이얼로그·바텀시트 조작 가능
- [ ] 포커스 이동과 다이얼로그 복귀 지점 확인
- [ ] 색상만으로 수입·지출·저축·상태를 구분하지 않음

## 6. 안전·개인정보

- [ ] 공개 동의 기본값 비공개
- [ ] 실명·계좌번호·거래 원문·직장·상세 위치 영구 제외
- [ ] 공개 철회 즉시 프로필·추천·캐시 제거
- [ ] 상품·종목 열람이 루틴·퀘스트·보상으로 변환되지 않음
- [ ] 수익률 경쟁, 추천 매수, 거래량 보상, 공개 순위 없음
- [ ] 로그·분석 이벤트에 정확 금융값과 인증정보 없음
- [ ] production에서 demo API와 원시 합성 번들 접근 차단
