## 2026-10-02: 백엔드 보강 당시 기록

아래 앱 검증은 당시 추가했던 대시보드의 기록입니다. 해당 화면은 이후 제거했으며, 현재 연결 범위는 예산 카드와 소비 탑 5입니다. 백엔드 정확성·SQL 실험 기록은 보존합니다.

기준: `169c037a759b1172006bc50e222c498512265bd4` + `codex/service-rebuild`의 미커밋 변경. Java 21.0.8, PostgreSQL 16.15, Docker Desktop. 실제 배포는 하지 않았습니다.

- 새 정확성·API 회귀 검증: 수정 전 14개 중 8개 실패. 100원/0원 평균 100원, 삭제된 집계 잔존, 자료 범위 누락, 타 persona 조회 200, 날짜 무시, 거래 경로 404를 직접 확인했습니다. 수정 후 14개 통과.
- 전체 `./gradlew test`: 60개 중 56개 실행·통과, 실패 0. 4개는 명시적 환경변수가 필요한 대규모·외부 이미지 실험으로 건너뜁니다. 핵심 DB 테스트는 개인 자료 유무로 건너뛰지 않습니다.
- 별도 `FINMATE_BENCHMARK=1 ... --tests '*PeerCompareQueryPlan'`: 통과. 네 쿼리 결과 일치, 원표본 160개 보존 및 백분위 별도 재검산.
- 새 Compose 프로젝트·빈 볼륨에서 이미지 빌드, Flyway 7개 migration, 24명·1,344행 적재, `/actuator/health` UP 확인.
- 앱 TypeScript·Vite 빌드 성공, lint 오류 0. 기존 시연 컴포넌트의 Fast Refresh 경고와 큰 초기 bundle 경고가 남아 있습니다.
- 앱 E2E: 데스크톱·모바일 각각 실제 API 시작·기간 조회·비교·자료 없음, 그리고 실패 응답 안내 검증. API 오류 시험만 503 응답을 주입합니다.

이번에 실제 은행 API·유료 이미지 생성·과거 HTTP 부하 실험을 실행하지 않았습니다. 운영 정확도·가용성·성능으로 일반화하지 않습니다.
