# FinMate vNext 디자인 시스템과 문구

## 1. 디자인 방향

FinMate는 금융 도구의 신뢰성과 RPG의 진행 감각을 함께 제공한다. 정보는 조용하고 정돈되게, 레이드 연출은 짧고 의미 있게 사용한다. 사용자를 평가하거나 과장된 성취를 유도하지 않는다.

원칙:

- 숫자와 데이터 상태가 캐릭터 장식보다 먼저 읽혀야 한다.
- 색상, 아이콘, 문구를 함께 사용해 상태를 전달한다.
- 카드 중첩과 장식용 그라디언트를 사용하지 않는다.
- 둥근 모서리는 최대 8px로 제한한다.
- 레이드와 캐릭터는 정보의 시각화이며 금융 결과를 대신하지 않는다.

### 2.2 타이포그래피

기본 서체는 시스템 한국어 산세리프(`Pretendard`, `Apple SD Gothic Neo`, `Noto Sans KR`, sans-serif)다. 숫자는 고정폭 숫자 기능을 사용한다.

| 토큰 | 크기/행간/굵기 | 용도 |
| --- | --- | --- |
| `type.display` | `32px/40px/700` | 목표 완료의 핵심 수치 |
| `type.title1` | `24px/32px/700` | 화면 제목 |
| `type.title2` | `20px/28px/700` | 주요 섹션 제목 |
| `type.title3` | `17px/24px/600` | 카드·리포트 제목 |
| `type.body` | `16px/24px/400` | 기본 본문 |
| `type.bodyStrong` | `16px/24px/600` | 행동·강조 본문 |
| `type.label` | `14px/20px/600` | 버튼·탭·필드 라벨 |
| `type.caption` | `13px/18px/400` | 기준일·보조 설명 |

글자 간격은 모두 `0`이다. 뷰포트 너비에 따라 글자 크기를 자동 확대·축소하지 않는다.

### 2.3 간격·크기·형태

- 간격: `space.1=4`, `2=8`, `3=12`, `4=16`, `5=20`, `6=24`, `8=32`, `10=40`, `12=48`px
- 모서리: `radius.none=0`, `sm=4`, `md=8`px
- 테두리: `border.hairline=1px`, `border.focus=2px`
- 그림자: 바텀시트와 모달에만 `0 8px 24px rgba(23,26,31,0.16)` 사용
- 최소 터치 영역: `44×44px`
- 모바일 콘텐츠 여백: `16px`, 태블릿 이상: `24px`
- 읽기 콘텐츠 최대 너비: `720px`, 대시보드 최대 너비: `1120px`
- 하단 내비게이션: 높이 `64px`, 네 항목 균등 배치
- 카드·퀘스트 행: 콘텐츠에 따른 높이, 최소 `72px`

## 3. 상태 표현

| 상태 | 아이콘·색상 | 제목 예시 | 행동 |
| --- | --- | --- | --- |
| 최신 | 체크·성공 | `최신 데이터예요` | 없음 |
| 반영 대기 | 시계·정보 | `새 데이터 반영을 기다리고 있어요` | 연결 주기 보기 |
| 오래됨 | 달력 경고·주의 | `진행 계산을 잠시 멈췄어요` | 연결 상태 확인 |
| 부족 | 정보·중립 | `목표를 계산할 데이터가 더 필요해요` | 시작 목표 보기 |
| 확인 필요 | 느낌표·주의 | `확인할 거래가 3건 있어요` | 거래 확인 |
| 오류 | 경고 삼각형·위험 | `새 정보를 불러오지 못했어요` | 다시 시도 |
| 오프라인 | 연결 끊김·중립 | `저장된 정보를 보여드려요` | 연결 후 다시 시도 |

스켈레톤은 1.2초 주기의 낮은 대비 밝기 변화만 사용한다. 10초 이상 걸리는 진단은 현재 단계와 취소 또는 나중에 계속하기를 제공한다. 퍼센트만 있는 무기한 로딩은 사용하지 않는다.

## 4. 컴포넌트 목록

### 내비게이션과 행동

- 하단 내비게이션: 홈, 메이트, 퀘스트, 기록 아이콘과 라벨
- 상단 앱 바: 화면 제목, 뒤로, 문맥 메뉴
- 아이콘 버튼: 닫기, 정보, 필터, 더보기, 이전/다음; 익숙하지 않은 아이콘은 툴팁 제공
- 주요 버튼: 화면당 한 개, 동사 중심 라벨
- 보조 버튼: 취소, 나중에, 이전
- 분할 선택: 가볍게·표준·도전처럼 상호 배타적인 선택
- 토글·체크박스: 공개 동의와 독립 설정; 동의 체크는 사전 선택 금지

### 데이터와 상태

- 데이터 상태 바: 상태, 마지막 동기화, 검증 출처, 관련 행동
- 핵심 수치: 값, 단위, 기준 기간, 변화 이유
- 진행률: 현재와 최고를 함께 표시하고 텍스트 값을 제공
- 단계 표시기: 1·2·3단계, 해금·현재·예정 상태
- 빈 상태: 원인, 결과, 한 가지 다음 행동
- 인라인 알림: 정보·주의·오류·완료
- 추세 차트: 선/점과 텍스트 요약, 색상 외 패턴·레이블 제공

### 콘텐츠

- 추천 모험가 카드: 익명 외형, 유사 이유, 대표 루틴, 기간, 지표 구간, 기준일, 공개 배지
- 그룹 루틴 카드: 정확 코호트가 30명 미만일 때 비금융 생활맥락만 넓혀 찾은 `cohortSize >= 30` 안전 코호트의 MVP 프라이버시 대체 카드. 개인 닉네임·외형·유지기간은 표시하지 않으며, 안전 코호트가 없으면 카드 컴포넌트 대신 `INSUFFICIENT` 빈 상태를 쓴다.
- 목표 후보 행: 난이도, 목표값/범위, 기간, 검증 출처, 선택 상태
- 퀘스트 행: 제목, 영역, 상태, 남은 기간, 검증 출처
- 동물 리포트 탭: 곰·물개·토끼·새 아이콘과 텍스트 라벨
- 날짜 발판: 날짜, 대표 활동 1개, 보조 최대 2개, `+N`
- 바텀시트: 일일 기록과 짧은 선택에만 사용하며 카드 안에 다시 카드를 넣지 않는다.

### 레이드

- 전투장은 홈의 전체 폭 정보 영역이며 장식 카드 안에 넣지 않는다.
- 보스 이름, 현재 단계, 보스 HP, 데이터 상태를 텍스트로 함께 표시한다.
- 전투 연출은 새 데이터로 진행률이 변한 경우에만 최대 2.5초 재생한다.
- 진행률이 변하지 않으면 정적 대기 상태와 이유만 보여준다.
- `prefers-reduced-motion`에서는 위치 이동·흔들림·섬광 없이 전후 수치가 교체된다.

## 5. 문구 원칙

1. **평가보다 사실**: `잘했어요`보다 `저축 입금 1건이 확인됐어요`를 우선한다.
2. **원인과 영향**: 상태 제목 다음에 왜 그런지, 무엇이 멈추는지 설명한다.
3. **한 문장 한 행동**: 버튼은 `확인`, `계속`보다 `목표 확정`, `거래 확인`처럼 결과를 쓴다.
4. **실시간처럼 말하지 않기**: `곧 반영돼요` 대신 `연결 기관의 전송 주기에 따라 반영돼요`를 쓴다.
5. **비난하지 않기**: 목표 하락, 만료, 취소에 실패·벌점·손해 표현을 사용하지 않는다.
6. **AI를 주체로 과장하지 않기**: `AI가 목표를 만들었어요` 대신 `내 데이터로 계산한 후보를 순서대로 설명했어요`를 쓴다. `DETERMINISTIC_FALLBACK`에서는 AI 생성으로 표현하지 않는다.
7. **투자 중립성**: 매수·매도·수익 약속과 긴급성을 암시하지 않는다.
8. **개인정보 구체화**: `안전하게 보호`만 쓰지 않고 공개 항목과 비공개 항목을 열거한다.

## 7. 보스와 영역 문구

허용 보스 이름: `예산 흔들림`, `반복결제 매듭`, `비상금 공백`, `정보 안개`, `용어 미궁`.

금지 이름: 사용자의 소비·체형·성향·능력을 조롱하거나 사람을 적으로 표현하는 이름. `과소비 괴물`, `투자 겁쟁이`, `게으름 대장`을 사용하지 않는다.

동물 설명:

- 곰: `예산 범위 안에서 계획을 지킨 흐름을 살펴봐요.`
- 물개: `저축성 순유입과 비상금 흐름을 살펴봐요.`
- 토끼: `위험성향과 분산 판단을 점검해요. 거래를 추천하지 않아요.`
- 새: `생활관리, 학습, 기록에서 확인된 경험을 모아요.`

## 8. 접근성 기준

- WCAG 2.2 AA와 한국형 웹 콘텐츠 접근성 지침의 동등 항목을 목표로 한다.
- 화면 제목부터 논리적인 초점 순서를 제공하고 건너뛰기 링크를 지원한다.
- 모든 기능을 키보드로 사용할 수 있으며 초점 표시를 제거하지 않는다.
- 스크린리더 이름은 시각 라벨과 일치시킨다. 아이콘만 있는 버튼에는 목적과 결과를 포함한다.
- 오류는 필드와 연결하고 요약 영역에서도 제공한다. 수정 후 초점을 첫 오류로 이동한다.
- 차트는 같은 내용을 문장과 표로 제공한다. 진행률은 `현재 28%, 최고 35%, 1단계`처럼 읽힌다.
- 자동 재생 연출은 일시정지·건너뛰기가 가능하고 5초를 넘지 않는다.
- 동작 줄이기 설정에서는 전환 시간을 100ms 이하로 줄이고 섬광·진동·시차 이동을 제거한다.
- 200% 확대, 320 CSS px 너비, 큰 글자 설정에서 가로 스크롤 없이 핵심 흐름을 완료한다.
- 터치 대상은 최소 44×44px이며 인접 대상 사이에 8px 이상 간격을 둔다.
- 제한 시간은 사용하지 않는다. 동의와 목표 확정에는 검토 시간을 강제하지 않는다.

## 9. Phase 2 경계

- 친구·팔로잉 컴포넌트, 그룹 순위, 소셜 피드는 만들지 않는다.
- 알림 세부 설정과 레이드 연출 강도 제어는 Phase 2다. MVP는 운영체제 접근성 설정을 따른다.
- 관리자용 템플릿 편집 토큰과 화면은 이 디자인 시스템 범위에 포함하지 않는다.
- 금융상품·종목·쿠폰·포인트용 시각 언어를 추가하지 않는다.
