> 상태: Review  
> 형식: 본문 10장, 7분 발표, 90초 시연 포함  
> 주의: 기존 구현, 새 프로토타입, 후속 계획을 한 문장 안에서 섞지 않는다.

| 시간 | 장 | 결론형 제목 | 증거·화면 |

| 6:10–6:50 | 10 | `사회적 호기심을 작은 금융행동으로 바꾸겠습니다` | 3단계 실행 계획과 마무리 |

## 상태 라벨

- `기존 검증`: 기존 합성데이터·API·분석에서 실제 확인한 범위
- `vNext 계약`: 이번 패키지에서 구현 가능하도록 정의한 범위
- `발표용 프로토타입`: API 미연동 UI·모션
- `후속 검증`: 사용자 테스트·실제 마이데이터·기관 파일럿

## 금지 표현

- 실제 고객 199명
- FinMate 효과가 검증됐다
- AI가 최적 목표를 생성한다
- 투자 성과를 게임 보상으로 제공한다
- 하나은행 도입이 확정됐다
- 친구·메이트 찾기가 MVP에서 동작한다
