# FinMate vNext 90초 시연 스토리보드

> 상태: Review  
> 모드: 고정 데이터 기반 결정적 HTML 프로토타입  
> 핵심 과제: 추천 모험가의 루틴을 내 목표로 가공하고 첫 행동과 기록까지 연결한다.

| 시간 | 장면 | 사용자 행동 | 화면에서 반드시 읽힐 것 |
| ---: | --- | --- | --- |
| 0–8초 | 목표 없는 홈 | `목표 설정` 선택 | 네 동물의 현재 상태, 마지막 동기화, 목표 없음 |
| 8–20초 | 비교 탐색 | 생활맥락 조건 확인, 추천 모험가 선택 | 익명·공개 동의, 루틴 유지기간, 정확 금액 미노출 |
| 20–32초 | 성장 방식 | `먼저 저축 루틴` 선택 | 루틴의 빈도·비율 구간·검증일 |
| 32–44초 | 목표 후보 | 가볍게·표준·도전을 비교하고 `표준` 선택 | 내 기준값, 목표값, 기간, 계산 근거 |
| 44–54초 | 목표 확정 | 공개 범위와 데이터 상태 확인 후 확정 | 사용자가 최종 결정, AI 자유 생성 아님 |
| 54–64초 | 자동 레이드 | 홈으로 복귀 | 1단계 보스, 현재·최고 진행률, 반영 대기 상태 |
| 64–74초 | 목표 연결 퀘스트 | `자동저축 설정 확인` 수행 | 퀘스트 XP와 금융 진행률 분리 |
| 74–84초 | 데이터 반영 | 동기화 완료 연출 | 계산 버전, 새 진행률, 레이드 갱신 이유 |
| 84–90초 | 기록 | 오늘 날짜 발판과 일일 기록 확인 | 수입·지출·저축 요약, 목표 이력, 마무리 문장 |

## 고정 목업 값

- 기준 여윳돈: `1,100,000원`
- 기존 저축률: `800 bp` (`8%`)
- 표준 목표: `1,400 bp` (`14%`)
- 기간: `6개월`
- 데이터 상태: 시작 `CURRENT`, 퀘스트 직후 `PENDING`, 반영 후 `CURRENT`
- 레이드 진행률: 시작 `0%`, 반영 후 예시 `12%`

## 시연 안전 규칙

- 특정 상품·종목·수익률을 표시하지 않는다.
- 퀘스트 완료와 목표 진행률 갱신 사이에 데이터 동기화 장면을 둔다.
- 상대 모험가의 정확 금액과 순위를 표시하지 않는다.
- AI 코치 문장은 계산 결과를 바꾸지 않는다.
- 실제 연동처럼 보이지 않도록 마지막 장면에 `합성데이터 기반 프로토타입`을 표시한다.
