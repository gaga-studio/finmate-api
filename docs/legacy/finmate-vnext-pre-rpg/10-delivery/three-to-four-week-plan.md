# 4주 합성 데이터 MVP 개발 계획

## 1. 기간과 목표

기간은 2026-07-13 월요일부터 2026-08-07 금요일까지 4주, 20영업일이다. 목표는 계약 호환 어댑터와 합성 데이터로 비교 탐색에서 검증된 루틴을 선택하고, 결정론적 세 후보를 확정해 자동 레이드와 기록으로 이어지는 MVP 프로토타입을 인수하는 것이다. 실제 마이데이터 수집과 실제 사용자 파일럿은 이 일정의 완료 증거가 아니다.

팀 구성 기준은 제품 1, 디자인 1, 프론트엔드 2, 백엔드 2, 데이터 1, QA 1, AI·보안·개인정보 파트타임 리뷰다. 인원 변동 시 안전·계산·철회·접근성 범위를 줄이지 않고 AI 문장 다양화나 부가 연출을 먼저 축소한다.

## 4. 의존관계와 임계경로

```text
범위 동결(W1-01)
→ 계산·상태(W1-02) + 계약(W1-05)
→ 후보 흐름(W2-02)
→ 목표 상태(W2-03)
→ 레이드·퀘스트(W2-04/W2-05)
→ 전체 E2E(W3-04)
→ 최종 인수(W4-02)
→ 합성 릴리스 시뮬레이션(W4-05)
```

공개 카드 임계경로는 `W1-03 → W1-04 → W2-01 → W2-06 → W3-06 → W4-04`다. AI는 `W3-01~W3-03`이 지연돼도 전량 폴백으로 인수할 수 있어 임계경로에서 분리한다. 실제 마이데이터 어댑터는 post-MVP이며 MVP는 계약을 준수하는 합성 어댑터로만 검증한다.

## 5. 일일 운영

- 오전 10분: 임계경로, 안전·개인정보 차단 이슈, 결정 필요사항 확인
- 오후 15분: 통합 브랜치 상태, 계약 변경, 테스트 실패와 다음날 위험 확인
- 월·수·금: 스테이징 수직 여정 데모
- 화·목: 개인정보·AI·접근성 집중 리뷰
- 매일 종료 전: WBS 상태, 책임자, 완료 증거, 위험 레지스터 갱신

결정은 회의록에 선택지, 근거, 책임자, 적용 버전과 재검토 조건을 남긴다. 일정 지연은 완료율이 아니라 임계경로와 안전 게이트 영향으로 보고한다.

## 6. 3주 압축 조건

08-03에 3주 버전을 합성 데이터 내부 데모로 제시할 수 있으나 운영 연결이나 외부 확대는 하지 않는다. 압축이 필요하면 AI 생성 설명을 전량 폴백으로 전환하고, 보스 문구 변형과 부가 리포트 표현을 제외한다. 계산·동의·철회·삭제·접근성·보안·골든 테스트·운영 경보는 압축 대상이 아니다.

## 7. post-MVP 검증 경계

실제 마이데이터 제공자 연결, 운영 동의 문안 효력 검토, 실제 사용자 트래픽과 100명·4주 파일럿은 MVP 인수 후 별도 계획으로만 제안한다. 해당 제안은 새 위험 평가, 표본·기간 근거, 개인정보·법무 승인, 중지 기준과 독립 Go/No-Go를 가져야 하며 이 4주 WBS의 완료율이나 인수 증거로 소급하지 않는다.
