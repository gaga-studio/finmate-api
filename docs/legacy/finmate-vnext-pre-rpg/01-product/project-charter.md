# FinMate vNext 제품 헌장

## 1. 제품 정의

FinMate는 공개에 동의한 실제 익명 모험가의 검증된 금융 루틴을 내 데이터에 맞는 목표로 바꾸고, 실제 진행을 네 동물·퀘스트·3단계 자동 레이드로 이해하고 지속하게 만드는 금융 습관 서비스다. 정확 코호트의 적격 개인 표본이 30명 미만이면 개인 카드를 만들지 않고 비금융 생활맥락만 넓힌다. 금융 수용력 제약을 유지한 안전한 일반화 코호트가 30명 이상일 때만 집계 그룹 루틴 카드를 제공하며, 끝까지 30명 미만이면 `INSUFFICIENT`와 빈 결과를 제공한다.

제품의 본질은 다음과 같다.

> 금융진입장벽을 느끼는 청년들에게 사회적 호기심과 동기를 유발하여 금융친화력을 길러준다.

## 2. 해결할 문제

금융 초보 청년은 자신의 상태를 해석하기 어렵고, 일반적인 조언을 자기 상황에 맞는 행동으로 바꾸기 어렵다. 타인의 성과를 그대로 비교하면 압박과 수치심이 생기며, 게임 보상이 실제 금융 개선을 대신하면 잘못된 동기를 만든다.

FinMate는 세 가지 간극을 해결한다.

1. **발견 간극**: 나와 비슷한 사람이 실제로 유지한 루틴을 익명·구간 정보로 보여준다.
2. **개인화 간극**: 상대의 금액이 아니라 내 기준선과 승인된 규칙으로 목표 후보를 계산한다.
3. **지속 간극**: 실제 데이터 변화만 레이드 진행에 반영하고 작은 행동과 회고를 연결한다.

## 3. 핵심 사용자

- 금융 용어와 숫자 해석에 부담을 느끼는 만 19~34세 청년
- 소득·고정비·저축 여력이 서로 달라 일반적인 목표를 그대로 적용하기 어려운 사용자
- 경쟁이나 투자 수익 자극보다 생활 관리, 학습, 점검을 원하는 사용자
- 마이데이터 연결과 익명 루틴 공개 범위를 스스로 통제하고 싶은 사용자

## 4. 가치 제안

| 사용자 필요 | 제품 가치 |
| --- | --- |
| 어디서 시작할지 모르겠다 | 나와 비슷한 익명 모험가의 검증된 루틴을 발견한다. |
| 타인의 금액은 내 상황과 다르다 | 내 기준선으로 `가볍게·표준·도전` 목표를 계산한다. |
| 금융 상태를 읽기 어렵다 | 곰·물개·토끼·새가 네 영역을 쉬운 리포트로 설명한다. |
| 행동과 결과가 연결되지 않는다 | 실제 데이터가 확인될 때만 목표 진행률과 레이드가 움직인다. |
| 실패가 두렵다 | 지연·하락·만료에 벌점이나 손실을 주지 않고 다음 행동을 안내한다. |

## 5. 제품 원칙

1. **루틴을 참고하고 금액은 복사하지 않는다.** 추천 모험가는 사회적 호기심의 출처이며 목표값의 결정자가 아니다.
2. **코드가 후보를 만들고 AI는 허용된 후보만 순위화·설명한다.** 후보 ID와 금액·비율·기간·진행률은 승인된 규칙으로 만들고 검증한다. AI가 없거나 출력이 유효하지 않으면 코드가 결정론적으로 순위와 설명을 제공한다.
3. **실제 변화만 진행으로 인정한다.** 접속 시간, 전투 반복, 퀘스트 XP가 금융 스탯이나 목표 진행률을 대신하지 않는다.
4. **비교보다 자기 이해를 우선한다.** 잔액·연봉·수익률 순위와 공개 경쟁을 만들지 않는다.
5. **투자 행동을 게임화하지 않는다.** 거래, 투자금 증액, 수익률에 XP·배지·축하 효과를 주지 않는다.
6. **지연과 하락을 실패로 표현하지 않는다.** 현재 진행률과 최고 진행률을 분리하고 해금 단계는 유지한다.
7. **동의는 세분화하고 철회 가능해야 한다.** 마이데이터 수집과 익명 카드 공개를 별도로 관리한다.

## 6. MVP 결과물

MVP는 다음 하나의 완결된 경험을 제공한다.

`온보딩과 마이데이터 연결 → 기준선 진단 → 비교 탐색(안전한 일반화 코호트가 30명 이상이면 집계 그룹 루틴 카드, 아니면 빈 결과) → 루틴 선택 → 내 목표 후보 비교·확정 → 3단계 자동 레이드 → 목표 연결 퀘스트 → 데이터 반영 → 리포트와 30일 기록`

MVP 포함 범위:

- 생활맥락·고민·성향·공개설정·마이데이터 연결·기준선 진단의 6단계 온보딩
- 곰(소비), 물개(저축), 토끼(투자 판단), 새(퀘스트·금융지식)와 영역별 리포트
- 목표 미설정 홈, 활성 목표, 대기, 일시정지, 재설정, 완료 상태
- 비교 탐색, 추천 모험가 카드, 성장 방식, 루틴 선택
- 정확 코호트가 30명 미만일 때 비금융 생활맥락만 넓혀 찾은 30명 이상 안전 코호트의 집계 그룹 루틴 카드와, 그런 코호트가 없을 때 카드 없는 `INSUFFICIENT` 상태
- 7개 목표 템플릿과 세 난이도 후보, 사용자 확정
- 목표 생명주기, 3단계 자동 레이드, 목표 연결 퀘스트
- 30일 금융 여정, 일일 기록, 목표·단계 이력
- 서버 허용 후보 ID만 다루는 AI 순위·설명의 구조 검증, 결정론적 순위 폴백과 감사 로그

## 7. 명시적 비목표

- 친구·팔로잉, 친구 피드, 친구와 함께한 기록
- 유사그룹 탐색 화면, 그룹 루틴 탐색·필터, 그룹 집계 인사이트
- 금융상품·투자종목 탐색, 가입·매수·매도 유도
- 투자금액·수익률·거래 횟수 목표
- 사용자 공개 순위, 파티 기여도, 잔액·연봉 경쟁
- 포인트·쿠폰·현금성 혜택, 확률형 보상
- 시간 누적 피해, 재도전 횟수, 오프라인 전투 횟수
- 자동 마케팅 푸시와 시세 자극 알림
- 목표 템플릿 관리자 도구와 운영 콘솔

## 8. 성공 기준

### 핵심 퍼널

`추천 카드 노출 → 성장 방식 보기 → 루틴 선택 → 후보 확인 → 목표 확정 → 퀘스트 시작 → 검증된 첫 행동 → 1단계 도달`

### 제품 지표

- 성장 방식 보기 전환율, 루틴 선택률, 목표 확정률
- 검증된 첫 행동 완료율, 4주 습관 유지율
- 1·2·3단계 도달률, D7·D28 재방문율
- 사용성 과제 완료율 80% 이상
- “상대의 돈이 아닌 루틴을 가져온다” 이해율 80% 이상
- “투자 판단은 투자금·수익률 경쟁이 아니다” 이해율 90% 이상

### 가드레일 지표

- 투자 유도 문구·보상 발생 0건
- AI의 잘못된 후보 ID·수치 노출 0건
- 공개 철회 후 추천 제외 최대 24시간 이내
- 목표 과도성, 비교 압박, 계산 불일치 신고를 출시 판정에 함께 사용

## 9. 출시 원칙과 책임

- 제품·데이터·준법 책임자가 목표 템플릿, 공개 정책, 투자 가드레일을 승인한다.
- 계산 버전, 템플릿 버전, 동의 버전, 진행 스냅샷을 보존해 결과를 재현할 수 있어야 한다.
- AI 순위·설명이 실패해도 결정론적 순위와 설명으로 목표 선택·확정·취소와 리포트 핵심 정보를 사용할 수 있어야 한다.
- 개인정보 공개 철회와 마이데이터 연결 철회는 핵심 탐색 경로에서 접근 가능해야 한다.

## 10. Phase 2 경계

Phase 2는 MVP의 목표 계산·진행 모델을 바꾸지 않고 사회적 탐색과 운영 제어를 확장한다.

- 친구의 공개 루틴, 팔로잉, 함께한 기록
- 유사그룹 탐색, 그룹 루틴 탐색·필터, 집계 인사이트
- 목표 템플릿 관리자 승인 시스템
- 실제 마이데이터 사업자 어댑터 고도화
- 알림 설정과 레이드 연출 강도 설정

Phase 2에서도 정확 금융값 공개, 투자 거래 게임화, 공개 순위는 도입하지 않는다. 금융상품 탐색과 제휴 혜택은 Phase 3의 별도 규제·소비자보호 검토 대상으로 남긴다.
