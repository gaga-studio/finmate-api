# FinMate vNext 용어집

이 문서의 표기와 정의는 제품·UX 문서의 단일 기준이다. 화면 문구는 가능한 한 한국어 사용자 용어를 사용하고, 영문 상태 코드는 개발 계약에서만 병기한다.

| 표준 용어 | 정의 | 사용 규칙 |
| --- | --- | --- |
| FinMate | 실제 익명 루틴을 내 목표로 바꾸고 실제 진행을 보여주는 금융 습관 서비스 | `핀메이트`로 음차하지 않는다. |
| 모험가 | 공개에 동의한 실제 익명 사용자 또는 현재 사용자의 게임 표현 | 추천 출처에는 항상 `익명`과 공개 범위를 함께 설명한다. |
| 추천 모험가 | 공개·기간·품질·그룹 검증을 통과하고, 적격 개인 표본 30명 이상일 때 비교 탐색에 노출되는 익명 사용자 | 목표값을 주는 사람으로 표현하지 않는다. |
| 그룹 루틴 카드 | 정확 코호트가 30명 미만일 때 비금융 생활맥락만 넓혀 찾은 30명 이상 안전 코호트의 집계 루틴 카드 | 비교 탐색 안의 MVP 프라이버시 fallback으로만 사용한다. `cohortSize >= 30`을 필수로 하고 특정 개인의 닉네임·외형·유지기간을 사용하지 않으며, 안전 코호트가 없으면 카드를 만들지 않는다. |
| 유사 출발점 그룹 | 소득 규칙성, 고정비 부담, 여윳돈, 시작 지표, 목표 영역이 유사한 집단 | 적격 개인 표본의 최소 기준은 30명이며, 그룹 탐색·필터·인사이트는 Phase 2다. |
| 루틴 | 추천 모험가가 검증 기간 동안 반복한 금융 행동 | 정확 금액보다 행동과 유지 주기를 중심으로 표현한다. |
| 빌드 | 루틴, 유지기간, 검증 근거를 묶은 따라하기 단위 | 사용자 문구에서는 주로 `성장 방식`을 사용한다. |
| 성장 방식 | 빌드의 사용자 친화적 명칭 | 버튼은 `성장 방식 보기`로 통일한다. |
| 목표 템플릿 | 지표, 기간, 안전 범위, 검증 방식이 사전 승인된 버전 규칙 | 진행 중 목표는 확정 시 버전을 유지한다. |
| 목표 후보 | 템플릿과 내 데이터로 계산한 가볍게·표준·도전 선택지 | 확정 전에는 진행률이나 금융 상태를 바꾸지 않는다. |
| 가볍게 | 기준선에서 참고값까지 25% 이동하는 정량 난이도 | 우열이나 사용자 능력 평가로 표현하지 않는다. |
| 표준 | 기준선에서 참고값까지 50% 이동하는 정량 난이도 | 기본 추천 순서의 첫 항목이다. |
| 도전 | 기준선에서 참고값까지 75% 이동하는 정량 난이도 | 과도성 경고와 사용자의 자유로운 거절을 보장한다. |
| 기준선 | 목표 계산에 사용하는 소득, 필수지출, 지표, 기간, 분류 규칙의 확정 시점 스냅샷 | 목표 도중 자동 변경하지 않는다. |
| 기준 월소득 | 정규소득 3개월 또는 불규칙소득 6개월의 완료월 세후 소득 중앙값 | 일회성 입금은 제외한다. |
| 필수지출 | 월세, 관리비, 통신, 정기 교통, 보험, 부채상환 | 사용자가 오분류를 수정할 수 있다. |
| 여윳돈 | 기준 월소득에서 필수지출을 뺀 값 | 0 이하이면 비율형 목표를 만들지 않는다. |
| 활성 목표 | 사용자가 후보 하나와 검증·동의 조건을 확인한 뒤 진행 중인 유일한 목표 | 한 번에 하나만 허용한다. |
| 현재 진행률 | 최신 검증 데이터로 계산한 목표 도달 정도 | 실제 데이터에 따라 하락할 수 있다. |
| 최고 진행률 | 목표 기간 중 검증된 가장 높은 진행률 | 단계 해금과 과거 기록의 기준이다. |
| 금융 스탯 | 소비·저축·투자 판단의 현재 상태를 나타내는 지표 | 목표 진행률·퀘스트 XP와 분리한다. |
| 퀘스트 XP | 생활관리·학습·기록 행동의 검증된 누적 | 금융 스탯이나 목표 진행률을 대신하지 않는다. |
| 자동 레이드 | 목표 진행률을 세 단계 전투로 보여주는 시각 표현 | 시간이나 반복 횟수로 진행하지 않는다. |
| 레이드 단계 | 전체 진행률 0~33%, 33~66%, 66~100%의 세 구간 | 해금한 단계는 다시 잠그지 않는다. |
| 보스 | 사용자가 해결하려는 장애물의 상징 | 사람·소비 자체를 비난하는 이름은 금지한다. |
| 퀘스트 | 활성 목표를 돕는 작은 일일·주간 행동 | 보스 HP를 직접 줄이는 버튼으로 표현하지 않는다. |
| 곰 | 소비 영역과 소비 방어력을 나타내는 동물 | 예산 범위 유지와 반복지출 점검을 설명한다. |
| 소비 방어력 | 예산 범위 안에서 계획을 유지한 상태 | 소비를 적게 할수록 무조건 높아지는 지표가 아니다. |
| 물개 | 저축 영역과 저축 HP를 나타내는 동물 | 저축성 순유입·비상금·자동저축을 설명한다. |
| 저축 HP | 저축성 순유입, 자동저축 유지, 비상금 진행 상태 | 만기 재예치를 새 저축으로 중복 계산하지 않는다. |
| 토끼 | 투자 영역과 투자 판단력을 나타내는 동물 | 거래나 수익이 아닌 점검과 학습을 설명한다. |
| 투자 판단력 | 위험성향 일치, 자산 쏠림 점검, 분산 개념 학습 상태 | `투자 공격력`을 사용하지 않는다. |
| 새 | 퀘스트·금융지식 영역과 퀘스트 XP를 나타내는 동물 | 투자 거래를 성장 근거로 삼지 않는다. |
| 금융 여정 | 최근 30일의 금융 활동, 퀘스트, 목표 변화를 날짜별로 보는 기록 | 전투 반복 횟수는 포함하지 않는다. |
| 최신 | 템플릿이 허용한 기간 안에 동기화된 데이터 상태 | 정상 계산한다. |
| 반영 대기 | 행동은 있었으나 새 마이데이터가 아직 도착하지 않은 상태 | 이전 검증값을 유지한다. |
| 오래됨 | 허용 기간보다 오래된 데이터 상태 | 진행 계산을 중지하고 마지막 동기화를 표시한다. |
| 부족 | 정량 기준선에 필요한 최소 기간을 충족하지 못한 상태 | 행동형 시작 목표만 제공한다. |
| 확인 필요 | 분류 충돌, 중복, 이상치가 있어 사용자 판단이 필요한 상태 | 확인 전 목표값에 반영하지 않는다. |
| 재설정 필요 | 소득·필수지출 변화 등으로 기존 기준선을 다시 확인해야 하는 상태 | 목표를 자동 수정하지 않는다. |
| 일시정지 | 목표 상태가 `일시정지`로 유지되어 새 데이터로 진행률·레이드를 갱신하지 않는 상태 | 목표 연결 퀘스트도 `일시정지`되어 완료·퀘스트 XP 지급이 중단되고 기록은 유지된다. 포인트·현금성·경제적 보상은 MVP에 존재하지 않는다. |
| 완료 | 목표 100%가 검증된 종료 상태 | 이후 지표 하락과 과거 달성 기록을 분리한다. |
| 만료 | 목표 기간이 끝나 손실 없이 종료된 상태 | 실패로 표현하지 않는다. |
| 취소 | 사용자가 목표를 종료한 상태 | XP 차감이나 보스 회복을 적용하지 않는다. |
| 마이데이터 | 사용자의 동의에 따라 연결·전송되는 금융 데이터 | 실시간 반영으로 표현하지 않는다. |
| 익명 카드 공개 동의 | 자신의 검증된 루틴을 구간 정보로 추천에 사용할 수 있게 하는 선택 동의 | 마이데이터 수집 동의와 분리한다. |
| 데이터 기준일 | 화면의 값이 유효한 마지막 계산 기준 시점 | 목표·홈·리포트에 표시한다. |
| 검증 출처 | 목표 또는 퀘스트 완료를 판정하는 마이데이터·설정·앱 활동 | 사용자에게 쉬운 명칭으로 노출한다. |
| AI 순위·설명 | 서버가 만든 허용 후보 ID 중 추천 후보를 고르고 허용 근거를 쉬운 문장으로 바꾸는 보조 정보 | 후보 ID·수치 생성과 거래 추천을 수행하지 않는다. 유효하지 않거나 사용할 수 없으면 코드가 같은 응답 계약으로 폴백한다. |
| Phase 2 | 친구·그룹 탐색·운영 도구·설정 확장을 다루는 후속 범위 | MVP 화면에 준비 중 기능으로 노출하지 않는다. |

## 금지 용어와 대체 표현

| 금지 표현 | 대체 표현 | 이유 |
| --- | --- | --- |
| 미션 XP | 퀘스트 XP | 퀘스트 용어로 통일한다. |
| 투자 공격력 | 투자 판단력 | 거래·수익 경쟁의 인상을 피한다. |
| 재도전 횟수 | 사용하지 않음 | 시간·반복 기반 진행을 만들지 않는다. |
| 실패, 패배 | 만료, 일시정지, 다시 확인 | 비난과 손실 인상을 피한다. |
| 보스가 회복했어요 | 최신 데이터로 현재 진행률이 달라졌어요 | 하락을 벌점처럼 표현하지 않는다. |
| 매칭도 92% | 월세 부담과 저축 시작점이 비슷해요 | 불투명한 점수 대신 이유를 설명한다. |
| 과소비 괴물 | 예산 흔들림 | 사용자를 비난하지 않는다. |
| 투자 겁쟁이 | 정보 안개 | 성향을 조롱하지 않는다. |
